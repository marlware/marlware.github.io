I study computer science in the San Francisco Bay Area. I'm a backend developer who mostly writes Java and Spring Boot. I like making small but complete versions of real systems to see how they hold up.

Things I'm interested in:

  • Backend Java and Spring Boot. Building services with Spring Boot, from REST APIs and data access to messaging and testing.
  • Scala, Kotlin, etc. Functional programming on the JVM, and tools like Akka, Pekko, and Cats Effect; Coroutines, Ktor, and using Kotlin alongside Spring Boot.
  • Event-driven systems. Putting a queue like Kafka between the fast part of a system and the slow, unreliable part.
  • Stateful stream processing. Programs that read a nonstop flow of events and remember what came before, built with tools like Spark and Flink.
